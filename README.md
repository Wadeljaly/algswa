# "القصواء" - نظام إدارة نقاط البيع العربي الذكي

## الأهداف والميزات
نظام **"القصواء"** هو حل شامل ومرن ومجاني بنسبة ١٠٠٪ لإدارة الأعمال الصغيرة والمتوسطة، مصمم بلمسة عصرية باستخدام تقنية **Neumorphism** لضمان تجربة مستخدم متميزة.

### الميزات الرئسية:
* **نظام تسجيل دخول آمن**: واجهة حماية بكلمة مرور.
* **لوحة معلومات ذكية**: رسوم بيانية وإحصائيات محدثة في الوقت الفعلي.
* **إدارة المخزون**: متابعة المنتجات، التصنيفات، تنبيهات نقص الكمية.
* **واجهة نقاط البيع (POS)**: محرك بيع سريع يدعم اختيار العملاء وطباعة الفواتير.
* **إدارة العملاء والديون**: تتبع مديونيات العملاء والمعاملات المالية.
* **التقارير**: تحليل المبيعات، الأرباح، والضرائب.
* **النسخ الاحتياطي والاستعادة**: تصدير واستيراد البيانات بصيغة JSON.
* **دعم RTL كامل**: واجهة عربية متكاملة تماماً.
* **ثيم مضيء وداكن**: يدعم التبديل السهل لملاءمة بيئة العمل.

## المواصفات التقنية
* **التقنيات المستخدمة**: HTML5, CSS3 (Vanilla), JavaScript (ES6).
* **قاعدة البيانات**: `localStorage` (تعمل محلياً بالكامل).
* **الأيقونات**: Lucide Icons.
* **الرسوم البيانية**: Chart.js.
* **قابلة للتحويل**: جاهزة للتحويل لتطبيق سطح مكتب باستخدام Electron.

## مطور النظام
* **الاسم**: محمد الجعلي الحسين
* **الترخيص**: مجاني ومفتوح المصدر (Open Source)
